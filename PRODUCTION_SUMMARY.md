### 🚀 Quick Start

1. **Activate Theme**
   - Go to WordPress Admin
   - Appearance → Themes
   - Find "Swarnim Bharat Manch"
   - Click "Activate"

2. **Configure Homepage**
   - Settings → Reading
   - Select "A static page"
   - Create/choose homepage
   - Save

3. **Customize**
   - Appearance → Customize
   - Set colors, logo, contact info
   - Publish changes

4. **Create Content**
   - Dashboard → News/Projects/Events/Gallery
   - Add content with featured images
   - Publish
